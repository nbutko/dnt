M4 Implementation Plan — Ship It

Getting the game onto the Chromebook: hosting, an installable/offline PWA, and a real favicon.

feature: m4-ship-it · author: nbutko · opened: 2026-07-08 · status: done · PRD: no (none was written for M4) · wireframes: no (none was written for M4)

Reconstructed 2026-09-12 from the maintainer's session memory and git history — no plan existed for M4 when it shipped. Rebuilt from commits b54fcb4, 176afd3, 6258e29, 67ead92 (all 2026-07-08). Evergreen home: architecture.html's hosting section.

M4's goal per the roadmap was simply to get the game playable on the actual target device: hosted somewhere stable, installable as an app icon, and working offline. No PRD or wireframes were written — this was infrastructure work with no new screen or player-facing decision to argue for, just a plan's worth of stories to execute.

Stories & tasks

  • ☑ GitHub Pages deploy (b54fcb4, re-triggered by 176afd3). Set vite.config.ts's base to /dnt/ for the production build only (dev stays at root); added .github/workflows/deploy.yml to build with npm ci && npm run build and publish dist/ via actions/upload-pages-artifact + actions/deploy-pages on every push to main. 176afd3 was an empty re-trigger once Pages' Source setting was switched to "GitHub Actions" in the repo's own settings (a one-time manual toggle, not something a commit can do). Live at nbutko.github.io/dnt.
  • ☑ Hand-rolled PWA (6258e29). Added public/manifest.webmanifest (standalone display, the favicon as its icon) and a dependency-free public/sw.js (network-first for navigations so deploys propagate, cache-first for hashed assets and Google Fonts) — written by hand rather than via vite-plugin-pwa/workbox specifically so it can't break under rolldown-vite (see the PWA note). Registered production-only from main.tsx; sw.js added to ESLint's ignorePatterns as a browser SW-globals script outside the typed app graph.
  • ☑ Real favicon (67ead92). Replaced the template favicon with a gold d20 on a "bright brown" radial plate, traced from Die.tsx's gold variant and using the borderGold/accentGold token family; no face number (muddies the mark at 16px). One SVG serves the tab favicon, the PWA/home-screen icon, and apple-touch-icon.
  • ☐ Install + offline test on the real Chromebook — the roadmap's literal M4 deliverable. Never recorded as done in any commit or session memory; still open as of this reconstruction. Whoever picks this up should tick it here once it's actually been run on the device, not assume the PWA plumbing above is equivalent to having tried it.

What's still true

The game is a public static SPA with no backend — the save lives in the browser's IndexedDB, so progress is per-device (no cross-device sync, by design). Google Fonts still load from the CDN at runtime rather than being self-hosted; the service worker just caches them after first use. See the base-path note for the dev-vs-build split and deploy trigger, and the PWA note for the service worker's caching strategy.
