Notes

Dated gotchas and context dumps. Read the one-sentence "relevant when" here, then the head of the note, then the rest only if it still applies.

A note is written when an agent learns something non-trivial that the next agent is likely to trip on. Notes are named YYYYMMDD-author-topic.html, open with a short "when to read this" summary, and are never quietly corrected: a later author who finds one wrong marks it with a loud banner and updates its line here. Conventions in full: see the docs-refactor PRD until the evergreen conventions doc lands.
