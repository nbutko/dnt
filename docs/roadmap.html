Roadmap & Milestones

Something playable at every step, in build order.

Each milestone is scoped to produce something that can actually be handed to him to try — no milestone is "invisible plumbing only." Scope stays deliberately small per step; a layer expands once it's proven fun.

Where we are, what's next

The game is mid-M5: the core loop (map → dungeon → typed battles → D&D character → Shop) shipped in M0–M4 and is live on the Chromebook. M5 is the open-ended playtest/balance/content loop that keeps that loop honest. Its plan is plans/wip/20260710-nbutko-m5-game-mechanics.html (PRD: the game-mechanics audit), nineteen stories in four phases; none have shipped as of this writing, so the next phase is Phase A — live bug fixes (Stories 1–8: the two reported bugs plus every other item on the bug ledger, nothing new, everything solid) before Phase B's balance pass. M6 is the optional visual upgrade after that.

M0 — Combat math spike shipped

The battle math (damage formula, HP, timers, monster typing simulation) as plain functions with no UI polish, proven on an unstyled page before any art or animation was invested. Plan: plans/done/20260704-nbutko-m0-combat-spike.html (no PRD was written — nothing preceded the math to record).

M1 — Playable vertical slice shipped

One real UI — prompt display, countdown, HP bars for both sides, win/lose screen — hardcoded to one monster and one text tier, the first "does this even feel fun" checkpoint before progression was built on top. No artifacts recorded for this milestone.

M2 — Progression loop shipped

The save file (IndexedDB), the world map (Inn, Shop, and habitat-themed dungeons), hearts/lives, coins, XP, and the original skill tree. Scope: prds/done/20260704-nbutko-m2-progression-loop.html; build: plans/done/20260704-nbutko-m2-progression-loop.html. The skill tree it shipped was retired in M3, replaced by ability scores and 5e leveling.

M3 — The character sheet (the D&D layer) shipped

The D&D concepts the typing game was missing — six ability scores, 5e-style leveling (which replaced the M2 skill tree), classes, character creation, dice rolls (an encounter d20 plus per-hit weapon damage dice), equippable weapons, consumable items, and the Shop. The full loop now plays like a role-playing game, not a math worksheet, still without a single image asset. Scope: prds/done/20260705-nbutko-m3-character-sheet.html; build: plans/done/20260705-nbutko-m3-character-sheet.html. See Codebase Architecture for the shipped shape.

M4 — Ship it shipped

Hosting (GitHub Pages, via a GitHub Actions build on every push to main), the PWA manifest and service worker, installed on the actual Chromebook. Plan (reconstructed from memory and git history — no contemporaneous doc was written): plans/done/20260708-nbutko-m4-ship-it.html.

Content v1 & v2 — the 14-tier ladder shipped

The text-tier content plan, superseded once by its own v2: the 14-tier difficulty ladder, the dungeon→tier mapping, and the generation pipeline that produces it, covered evergreen in content.html. v1 PRD: prds/done/20260704-nbutko-content-v1.html; v2 scope: prds/done/20260707-nbutko-content-v2-tiers.html; v2 build: plans/done/20260707-nbutko-content-v2-tiers.html.

Combat retune shipped

The damage-cap, per-tier-factor, and crit-wiring pass that closed the M3 crit-range gap (DEX and a weapon's crit range now move crit odds and damage). Scope: prds/done/20260708-nbutko-combat-retune.html; build: plans/done/20260708-nbutko-combat-retune.html. User feel-verification was never recorded.

M5 — Content & balance pass in progress

The ongoing playtest-driven loop: watch where he struggles or gets bored, and retune the character layer M3 handed off with placeholder numbers — M2's Focus/Luck/Utility skill branches were retired in M3 and absorbed into the six ability scores and D&D leveling, and it's here that layer gets its real numbers (XP-to-level pacing, per-modifier magnitudes, HP scale, weapon/item pricing, the fumble/inspiration knobs), alongside content and roster growth as the ladder expands. This milestone doesn't "end" — it's the ongoing content/balance loop for as long as the game keeps being played. Active plan and PRD linked above in Where we are, what's next.

M6 — Visual upgrade ahead, optional

Once the text-only game is proven and stable, swap in real monster art/sprites and pull in tier 7–10 long-form content (public-domain children's books, excerpted — see content-v1). This is deliberately last and deliberately optional — the game is already complete and playable without it.
